Replacement skill text, ready to paste. Skills are managed in Cowork, not in this repo.

| Skill | Action | File |
|---|---|---|
| `media-desk` | **Create** (new). Then switch off `video-batch-producer`. | `media-desk/SKILL.md` |
| `video-producer` | **Replace** its text with this. It adds HyperFrames to the ladder and drops the old five-site table. | `video-producer/SKILL.md` |

## How to apply, in Cowork

Say: "Use skill-creator to create a new skill called media-desk from the text in docs/cowork-skills/media-desk/SKILL.md
in the Command Hub repo. Then replace the text of the video-producer skill with docs/cowork-skills/video-producer/SKILL.md,
and turn off video-batch-producer."

If Cowork cannot read the repo, open each file and paste its whole contents.
