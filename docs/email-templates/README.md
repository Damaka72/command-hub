# Email templates

Evergreen email templates for each site: welcome emails, the regular issue layout, offer and
outreach emails. These are drafts for review. Anything in [SQUARE BRACKETS] is a slot to fill
before sending.

The same content is kept as Google Docs in the Command Hub Content Library on Google Drive.
If you edit one copy, update the other.
