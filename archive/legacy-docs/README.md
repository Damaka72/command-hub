drafting pipeline (`npm run pipeline`), per-site coordinators and a GitHub Actions trigger. They are kept
as a record. **Do not follow them.** They are not read by the app.

| `AGENT-IMPLEMENTATION.md` | Setup spec for the repo's agent pipeline. |

`docs/cowork-operating-guide.md`.
